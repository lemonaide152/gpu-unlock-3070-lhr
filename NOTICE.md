## Modifications (GPL-2.0 §2(a) notice)

`patches/0001-independent-display-runtime-profile.patch` changes three upstream files:

- `src/unlock/app.c`
  - `efi_main` loads `\RTX-UNLOCK\PROFILE.BIN` (`GuProfileLoad`) before any PCI
    access when it is built with `GU_RUNTIME_PROFILE_BUILD`. Without this, the
    classic path never loads a profile.
  - `DisplayCheck` accepts one pathless forwarder GOP even if it is not
    `ConsoleOutHandle`, as on AMI firmware. Its mode must still match the
    single independent physical GOP.
- `src/unlock/app_io.c`, `app_io.h`: add `GuIoParent()` for read-only access to `\RTX-UNLOCK`.

`tools/build-independent.ts` and `tools/build-probe-linux.ts` are new build
scripts. They use the same compiler and linker flags as upstream, minus
`GU_GOP_EXPERIMENT`, `GC_FULL_FLR`, `GC_FULL_UNLOCK`, `GC_WINDOWS_HANDOFF` and
`GU_AUTO_PROFILE` for the unlock build, plus a MinGW include path for building
on Linux.
